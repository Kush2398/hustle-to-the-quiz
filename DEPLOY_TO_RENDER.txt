LOCAL XAMPP SETUP
1. Start MySQL in XAMPP.
2. Open phpMyAdmin and import database.sql, OR let app.py create the database/tables.
3. Default MySQL settings: host 127.0.0.1, port 3306, user root, empty password.
4. If your root account has a password, set MYSQL_PASSWORD before running:
   Windows CMD: set MYSQL_PASSWORD=YOUR_PASSWORD
5. Install packages: pip install -r requirements.txt
6. Run: python app.py
7. PC: http://127.0.0.1:5000
8. Phones on same LAN: http://YOUR-PC-IP:5000

ADMIN LOGIN
Default ID: admin
Default password: admin123
You can change them with QUIZ_ADMIN_ID and QUIZ_ADMIN_PASSWORD.

IMPORTANT
- XAMPP/MySQL on your PC is for LAN/local event use.
- Do not use database.db.
- __pycache__ and .pyc files are generated automatically by Python and are not required in the project ZIP.
- All five events use the same MySQL database and are separated by event_id.
